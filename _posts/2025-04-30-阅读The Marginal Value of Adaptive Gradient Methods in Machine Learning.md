# The Marginal Value of Adaptive Gradient Methods in Machine Learning（2017）

“**Margin**”（边界）是机器学习中，尤其是**分类问题**中一个非常重要的概念，主要用于描述模型在做出预测时的**信心程度**。 

margin越大，泛化性能越强

“**Overparameterized problems**（过参数化问题）”是指模型的参数数量**远多于训练数据的数量**的情况。这是现代机器学习，尤其是**深度学习**中非常常见的一种现象。 

模型比数据“强大得多”，能拟合几乎任何东西。 解不唯一 。泛化能力依赖优化方法 

过参数化条件下 ，非自适应方法找到的解通常泛化性能更好

即使一个优化算法有很好的理论保证（比如低 regret），如果它要多次遍历数据才能达到最低训练误差，那它最终找到的模型未必能在新数据上泛化良好。 

自适应方法（如 Adam）虽然在训练上看起来“收敛更快”，理论上也有一些优化保证；

但这些“保证”**不代表**最终模型在测试集或真实数据上表现就一定好；

自适应优化器（例如 Adam）更容易把注意力放在那些对训练集有效、但对测试集无用的“假特征”上，因此它们的泛化能力更差。 



即使自适应方法在训练集上的损失更低，**测试性能仍然更差**。这说明它们容易**过拟合**。 

**自适应方法前期训练速度快**（下降迅速），但在验证/测试集上的表现**很快进入平台期**，提升空间小。 

**所有方法（包括自适应方法）都需要相同程度的调参工作**。
